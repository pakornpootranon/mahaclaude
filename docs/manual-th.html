ใช้งาน Mahachai Market Watch ให้เป็นภายใน 10 นาที

แดชบอร์ดเฝ้าข่าวการเงินส่วนตัว ที่ดึงข่าวจากหลายแหล่งตามหัวข้อที่คุณตั้งไว้ ให้ Claude วิเคราะห์ผลกระทบต่อหมวดธุรกิจ/หุ้นแต่ละตัว แล้วสรุปเป็นคำแนะนำ BUY / SELL / WATCH พร้อมเหตุผล ให้คุณอ่านและตัดสินใจเอง — คู่มือนี้พาไปทีละส่วนของหน้าจอ พร้อมตัวอย่างจริงจากระบบ

ไม่ใช่คำแนะนำการลงทุน ทุกคำแนะนำในระบบเป็นเพียงความเห็นเพื่อการวิจัยเบื้องต้น การตัดสินใจลงทุนเป็นความรับผิดชอบของคุณเองทั้งหมด ระบบนี้ไม่ส่งคำสั่งซื้อขายหรือวางเดิมพันใด ๆ โดยอัตโนมัติ

§1 ระบบนี้คืออะไร

ทุกครั้งที่ระบบ "รันรอบ" (cycle) มันจะไล่ทำ 6 ขั้นตอนอัตโนมัติ: ดึงข่าว → คัดกรองข่าวที่เกี่ยวข้อง → วิเคราะห์เชิงลึกด้วย Claude → ใช้กติกาที่ตั้งไว้ตัดสินว่าจะออกคำแนะนำหรือไม่ → สแกนโอกาสใน Polymarket → สรุปผลเป็นภาษาไทยทั้งหมด ผลลัพธ์แต่ละรอบจะไปโผล่ใน 6 แท็บของแดชบอร์ด อธิบายทีละแท็บด้านล่าง

§11 คำถามที่พบบ่อย

รันรอบแล้วแต่ Action feed ว่างเปล่า ผิดปกติไหม?

ไม่ผิดปกติ — ถ้าไม่มีข่าวไหนผ่านเกณฑ์ความมั่นใจ/magnitude ที่ตั้งไว้ รอบนั้นก็จะไม่มีคำแนะนำเลย แต่หน้า Digest จะยังมีบทวิเคราะห์ Thai ของทุกหัวข้อให้อ่านเสมอ ลองดูที่ "Analyzed storylines" ในหน้า digest เพื่อดูว่ามีข่าวอะไรถูกพิจารณาบ้างและทำไมไม่ผ่านเกณฑ์

ทำไมเวลาในระบบไม่ตรงกับเวลาประเทศฉัน?

ทุกเวลาในระบบแสดงผลเป็นเขต Asia/Bangkok (ICT, UTC+7) เสมอ ไม่ว่าเครื่องคุณจะตั้งเขตเวลาไว้อย่างไร

ต้องเปิด worker ตลอดเวลาไหม?

ถ้าต้องการให้รอบรันอัตโนมัติตามตารางเวลา หรือให้ปุ่ม "Run cycle now" ทำงานได้ทันที ต้องมี make serve รันอยู่ในเทอร์มินัลอีกหน้าต่างตลอดเวลา ถ้าต้องการรันแค่ครั้งเดียวใช้ make dev-worker แทนได้

การรันแต่ละรอบเสียเงินไหม?

รอบที่มีการวิเคราะห์ข่าว/สแกน Polymarket จะเรียกใช้ Claude API ซึ่งมีค่าใช้จ่ายจริงตามบัญชี Anthropic ของคุณ เพดานงบต่อเดือนตั้งค่าได้ที่ Settings → LLM (ค่าเริ่มต้น $15) เมื่อชนเพดาน ระบบจะหยุดการวิเคราะห์แต่ยังคงดึงข่าวและสรุปแบบย่อได้ตามปกติ

ข้อมูลของฉันปลอดภัยแค่ไหน?

แดชบอร์ดรันบนเครื่องของคุณเอง ผูกกับ 127.0.0.1 เท่านั้น เข้าจากเครื่องอื่นในเครือข่ายไม่ได้ และไม่มีระบบล็อกอินโดยตั้งใจ — ดังนั้นควรใช้บนเครื่องส่วนตัวเท่านั้น
